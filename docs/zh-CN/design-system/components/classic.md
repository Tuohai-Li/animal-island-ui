# 经典组件

这些组件在 v2.3.0 基础上恢复历史外观。来源和素材权利说明见
[CLASSIC-NOTICE.md](../../../../CLASSIC-NOTICE.md)。Time 与 Loading 沿用最新版实现。

## Phone

奶油色手机屏幕搭配三行三列历史应用图标。保持原始 527 × 788 比例，最大宽度
380px，随容器缩放。容器单位同步缩放原来的 136px 圆角、123px 图标及 32px 间距。
顶部展示欢迎语和十二小时制实时时钟，底部展示页面圆点。

应用使用原生按钮，包含中文可访问名称、黄色焦点轮廓和 `onAppClick(appId)` 回调。
每秒更新时钟，卸载时清理定时器。`greeting` 默认为 `Welcome!`，透传原生 div 属性。
遵循减少动态效果偏好，停止图标和屏幕动画。

## Wallet

钱袋叠在橄榄色胶囊上，支持 small（96 × 32px）、medium（132 × 42px）、large
（176 × 54px）。钱袋直径依次为 38 / 50 / 66px。白色等宽数字搭配暖棕阴影。
悬停时钱袋跳动，减少动态效果模式下关闭动画。根节点透传原生 div 属性。

数字金额添加自定义千分位分隔符，保留负号和小数；字符串原样展示。
`icon` 可替换默认钱袋图案。

## WeddingInvitation

最大宽度 420px 的响应式请柬，使用奶油纸张、粉彩花饰、16px 圆角、历史标题和
人物图案，以及两层暖色内框。内容依次为标题、插画、姓名、日期、场地、寄语和
可选的 160px 抽奖券。关闭抽奖券时同时移除凹口和预留空间。

支持定制文本、ReactNode 标题/寄语、日期时间、场地和抽奖号码。
ref 提供 `getElement()` 和异步 `exportAsImage(filename?)`。导出按钮在生成中禁用，
下载两倍尺寸 PNG，失败时显示可重试的错误提示。按需加载 PNG 渲染器，截图内嵌现有字体。
减少动态效果模式下停止花饰和心形动画。
